# Контрольная работа №3

Тема: адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта.

Основа - [КР1](https://github.com/klpBvcVc/KR1-fr-bk-679832), коммит `f6ebbb3`. Bootstrap и другие CSS-фреймворки не используются. Оформление, семантическая разметка, компоненты и базовые стили взяты из КР1.

Автор: Гордеев Я. А., ЭФБО-12-25.

## Описание

Магазин одежды и обуви содержит 20 товаров и семь HTML-страниц. Для товаров используется один шаблон `product.html?id=jacket`, поэтому отдельные страницы для каждого товара не нужны. Данные 20 товаров сохранены из предыдущего варианта проекта, а их отображение переписано на классы и компоненты КР1.

## Структура

- `index.html` - главная, популярные товары и преимущества;
- `catalog.html` - каталог 20 товаров и CSS-фильтры;
- `product.html` - общий шаблон товара;
- `order.html`, `contacts.html`, `size.html`, `404.html` - заказ, контакты, размеры и ошибка;
- `css/style.css` - базовые стили КР1;
- `css/responsive.css` - собственные медиазапросы и доступность;
- `js/products.js` - данные товаров и таблицы размеров;
- `js/product-page.js`, `js/order-page.js` - показ товара и выбор товара в заказе;
- `js/ui.js` - тема и кнопка «Наверх»;
- `js/main.js` - нативный dialog и базовая обработка формы;
- `js/accessibility.js` - мобильная навигация, ошибки форм, фокус и таблицы;
- `images/` - исходные фотографии и WebP-варианты;
- `lighthouse/` - отчёты проверки именно этой версии.

## Адаптивность

Mobile First: базовая раскладка для телефона, затем `min-width`.

| Ширина | Изменение |
| --- | --- |
| До 640 px | Одна колонка карточек, фильтр над каталогом |
| От 640 px | Две колонки карточек |
| От 768 px | Фото и описание товара, блок преимуществ в двух колонках |
| От 1024 px | Три колонки карточек, боковой фильтр, полное меню |

Перестройка написана в нашем `responsive.css` через CSS Grid и `grid-template-columns`. Шапка и формы используют Flexbox. Изображения имеют `srcset`/`sizes`, hero - `picture`. Таблицы прокручиваются внутри отдельного контейнера. Модальное окно учитывает высоту экрана.

## Доступность

Сохранены семантические элементы, подписи полей и заголовки таблиц. Добавлены skip-link, видимый фокус, текстовые ошибки со сводкой, управление меню с клавиатуры, доступные области таблиц и режим reduced motion. Нативный `dialog` закрывается по Escape. Переход к популярным товарам учитывает высоту шапки один раз.

Формы учебные: данные на сервер не отправляются.

## Проверка

Результаты раскладки и сценариев: [responsive-check.json](lighthouse/responsive-check.json). Lighthouse Accessibility: 100/100 на пяти страницах в обеих темах. Итоги: [summary.json](lighthouse/summary.json), HTML-отчёты рядом.

Проверяются все 20 товаров и шесть остальных страниц на 360, 430, 768, 1024 и 1440 px, выбор товара в заказе, формы, фильтры и клавиатурная навигация. Дополнительно проверены 54 сочетания около медиазапросов: [boundary-check.json](lighthouse/boundary-check.json). Проверки выполняются в Chromium/Brave. Физические устройства и Safari не проверялись.

## Запуск

Открыть `index.html` или запустить из папки проекта:

```sh
python -m http.server 8000
```

Затем открыть `http://localhost:8000`. Сборка и установка зависимостей не нужны. Шрифты Google Fonts требуют интернет; при их недоступности используются запасные шрифты.

Фотографии взяты из КР1, исходный источник - Unsplash. Личные заметки для защиты хранятся вне репозитория.
